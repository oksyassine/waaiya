## Description

Waaiya entfernt Musikinstrumente aus allem, was Ihr Computer abspielt, und behält die Stimme: Sprache, Vorträge und
Koranrezitation. Es funktioniert mit jeder App (Browser, Videoplayer, Spiele), live, auf Ihrem Computer.

- Ein Knopf: Waaiya filtert den Ton all Ihrer anderen Apps, bis Sie ihn erneut drücken.
- Links: Fügen Sie einen YouTube-, TikTok- oder Instagram-Link ein und sehen Sie ihn in Ihrem Browser mit
  eingeschaltetem Filter an. Waaiya startet zuerst den Filter und öffnet den Link nie ohne ihn.
- Frauengesang stummschalten (optional, für Männer): eine frühe Version, die noch nicht jedes Lied erkennt; Sprache
  bleibt erhalten.
- Im Fehlerfall Stille: Wenn der Filter von selbst stoppt, bleiben andere Apps stumm, statt Musik abzuspielen.
- Optionale Bildschirm-Unschärfe: verdeckt Frauen oder freizügige Bilder über jedem Fenster; Klicks erreichen trotzdem
  die Fenster darunter.
- Apps, die ungefiltert zu hören sind: wählen Sie Apps, die ihren Originalton behalten; sie werden weder gefiltert noch stummgeschaltet.
- Schutz für schwache Momente: Stoppen kann warten (zum Beispiel 30 Minuten) und dann erneut fragen, und Eltern können eine PIN festlegen.
- Einen Fehler notieren: markieren Sie Musik, die durchkam, oder eine versehentlich entfernte Stimme; Notizen bleiben auf Ihrem Computer.
- Bei der Anmeldung starten, wenn Sie möchten.
- Alles läuft auf Ihrem Computer. Nichts wird irgendwohin gesendet: kein Konto, keine Analyse, keine Werbung.
- Kostenlos und Open Source (AGPL-3.0)
- In 18 Sprachen: Arabisch, Englisch, Französisch, Urdu, Indonesisch, Türkisch, Bengalisch, Persisch, Malaiisch,
  Spanisch, Niederländisch, Deutsch, Italienisch, Russisch, Usbekisch, Swahili, Hausa und Somali.

Der Name stammt aus dem Koran: «وَتَعِيَهَا أُذُنٌ وَاعِيَةٌ», „und damit ein aufmerksames Ohr es behalte“ (Sure al-Ḥāqqa 69:12).

Es benötigt Windows 10 Version 2004 oder neuer. Ein schneller Computer liefert den besten Ton; auf einem langsamen
wechselt Waaiya von selbst zu Mono.
