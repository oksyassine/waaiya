## Description

Waaiya retire les instruments de musique de tout ce que joue votre ordinateur et garde la voix : la parole, les cours
et la récitation du Coran. Elle fonctionne avec les applis que vous utilisez (navigateurs, lecteurs vidéo, jeux), en direct, sur
votre ordinateur.

- Un seul bouton : Waaiya filtre le son de toutes vos autres applis jusqu'à ce que vous appuyiez à nouveau.
- Liens : collez un lien YouTube, TikTok ou Instagram et regardez-le dans votre navigateur avec le filtre actif. Waaiya
  lance d'abord le filtre et n'ouvre jamais le lien sans lui.
- Couper le chant des femmes (en option, pour les hommes) : une première version qui ne repère pas encore tous les
  chants ; la parole est conservée.
- En cas d'échec, le silence : si le filtre s'arrête de lui-même, les autres applis restent muettes au lieu de jouer la
  musique.
- En option, le floutage de l'écran : il couvre les femmes, ou les images indécentes, au-dessus de toutes les fenêtres ;
  les clics atteignent toujours les fenêtres en dessous.
- Applications entendues sans filtre : choisissez des applications qui gardent leur son d'origine ; elles ne sont ni filtrées ni rendues muettes.
- Protection pour les moments de faiblesse : l'arrêt peut attendre (par exemple 30 minutes) puis vous redemander, et un parent peut définir un code PIN.
- Noter une erreur : signalez une musique passée ou une voix retirée par erreur ; les notes restent sur votre ordinateur.
- Une icône près de l'horloge : ouvrez Waaiya, ou activez et arrêtez le filtrage, sans chercher l'application.
- Démarrer à l'ouverture de session, si vous le souhaitez.
- Tout tourne sur votre ordinateur. Rien n'est envoyé nulle part : ni compte, ni statistiques, ni publicité.
- Gratuite et open source (AGPL-3.0)
- En 18 langues : arabe, anglais, français, ourdou, indonésien, turc, bengali, persan, malais, espagnol, néerlandais,
  allemand, italien, russe, ouzbek, swahili, haoussa et somali.

Le nom vient du Coran : « وَتَعِيَهَا أُذُنٌ وَاعِيَةٌ », « et qu'une oreille attentive la retienne » (al-Hâqqa 69:12).

Elle demande Windows 10 version 2004 ou plus récent. Un ordinateur rapide donne le meilleur son ; sur un ordinateur
lent, Waaiya passe en mono d'elle-même.
